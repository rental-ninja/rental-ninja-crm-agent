# Rental Ninja product knowledge (names only)

The main features and their real names, from the Help Center docs (`ninja-docs`), so you know *what to search for*.
It holds no figures on purpose: no prices, fees, commissions, percentages, limits or timings. Every behaviour, limit
or number you write comes from `search_docs` / `search_changelog` in this session, and no price or fee goes in an
article. When this file and the tools disagree, the tools win: update this file (names only).

**Channel Manager / Gestión de Canales** (Airbnb, Booking.com and other OTAs)
- Limited sync and Full (Complete) sync
- "Update listing content" (manual content push)

**Direct Booking Website & Booking Engine** (Distribution > Websites)
- Branded direct-booking website on the manager's own domain or subdomain
- Instant Booking
- Magic Write (AI help for the website's texts, in several languages)

**Guest Module / Módulo de Huéspedes**
- Pre-Check-in Form (email reminders, optional SMS reminder; arrival details, contact, passport/ID and document photo)
- Online Guest Portal: address and map, contact and WiFi, self check-in code and instructions, booking payment
  status, Welcome Book / Guide
- QR code and Guest Login Code (portal access without the form)
- Guest mobile app

**Ninja Smart Pricing** (dynamic pricing)
- Base price with min/max limits, weekend and seasonality strategies, last-minute discounts, occupancy pace
- Price preview and manual overrides
- Channel markup
- Custom seasonality periods and long-stay pricing rules

**Accounting / Contabilidad**
- Statements and Payments / Payouts
- Recipients and their Strategies
- Scheduled Statements & Payments
- Exports: Booking Breakdown, General Income, Invoices per Recipient, Net Income per Recipient

**Task Module**
- Scheduled Jobs (tied to bookings, e.g. cleaning around check-out) and Recurring Jobs (not tied to bookings)
- Job Templates (checklists), assignment to a person or a Team Role
- Inspector (approves or rejects a completed job)
- Push notifications to the team

**Team Roles & Permissions**
- Roles: Team Owner, Administrator, Rental Manager, Rental Owner, Cleaning Staff, Check-in Agent, Maintenance Staff,
  Member
- Per-rental access and per-member permissions

**Triggers** (automation engine)
- Actions: Guest SMS, Guest message (OTA inbox or email), fixed-recipient SMS / Email, team notification, booking Tag
